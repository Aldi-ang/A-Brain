# Summary: Ponytail Philosophy Ingest

**Source**: a verbatim excerpt of the Ponytail skill's own rulebook text, as it appears in
Claude Code's session context when Ponytail mode is active.

## Why this was ingested

The [[../../PLAN-second-brain-integration.md|second-brain plan]] specifically positions
Ponytail as something that should be a documented, readable Concept page rather than
invisible magic the project owner can't see the reasoning behind — since Ponytail governs
real coding decisions made in the actual `kpm-inventory` repo on their behalf.

## Where it went

Turned directly into [[Ponytail Philosophy]] — the ladder of questions (does this need to
exist / is it already here / stdlib / native / existing dependency / one line / minimum
code), the root-cause-not-symptom rule for bug fixes, and the explicit list of things it
never simplifies away (security, input validation, explicit requests).
